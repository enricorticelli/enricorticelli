## 🚀 Progetti in evidenza

### 🔐 [social-login-keycloak](https://github.com/enricorticelli/social-login-keycloak)
> End-to-end social login senza mostrare la UI di Keycloak.

Il frontend ottiene un token Google/Facebook reale → il backend lo scambia con Keycloak → chiami le API protette col risultato. Pulito, pratico, production-ready.

`TypeScript` · `Keycloak` · `OAuth2` · `Google/Facebook Auth`

---

### 🛒 [demo-ecommerce](https://github.com/enricorticelli/demo-ecommerce)
> Backend e-commerce su microservizi con Clean Architecture e integrazione event-driven.

Niente over-engineering, niente cargo cult. Microservizi dove ha senso, monolite dove non ha senso spaccare tutto.

`C#` · `.NET` · `Clean Architecture` · `Event-driven`

---

### 🔍 [aspire-elasticsearch](https://github.com/enricorticelli/aspire-elasticsearch)
> Demo e-commerce con .NET Aspire + ricerca prodotti su ElasticSearch.

Orchestrazione moderna con Aspire, ricerca full-text seria con Elastic. Stack completo, zero compromessi.

`TypeScript` · `.NET Aspire` · `ElasticSearch`
